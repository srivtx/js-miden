# E05 Social Media Platform — Changelog

## 1.0.0 (Phase 1)
- Initial release with 10 microservices
- User registration, authentication, profiles
- Posts, comments, likes, shares, stories (24h expiry)
- Direct messages (plaintext storage — known bug)
- Feed aggregation
- Notifications
- Search indexing
- Recommendations
- Media upload metadata
- Content moderation reports
- Ad campaign mock tracking

## Planned (Phase 2)
- End-to-end encryption for DMs
- PostgreSQL persistence
- Redis caching for feeds
- Elasticsearch for search
- Real-time WebSocket notifications
- S3-compatible media storage
- CI/CD and Kubernetes manifests
