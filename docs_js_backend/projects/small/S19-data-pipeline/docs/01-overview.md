# 01-overview.md

## WHAT

An ETL (Extract, Transform, Load) pipeline that ingests CSV data, validates and enriches it, and loads it into a database.

## WHY

ETL pipelines move data between systems, clean it, and prepare it for analysis. They are foundational for data warehouses and analytics.

## HOW

- Extract: Read from CSV
- Transform: Validate, normalize, enrich
- Load: Insert into destination store
- Track: Monitor pipeline status and metrics
