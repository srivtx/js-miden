# Thinking Exercises

## 1. The Consistency

User logs in on phone and desktop. Should they see the same variant?

**Question:** What are the trade-offs?

---

## 2. The Rollback

A feature flag causes a bug. You disable it.

**Question:** What happens to users who already have data in the new format?

---

## 3. The Test Matrix

You have 5 feature flags. Each can be on or off.

**Question:** How many combinations? Can you test them all?

---

## 4. The Analytics

50% of users see variant A. But only 30% complete the funnel.

**Question:** Is variant A worse? Or is there selection bias?

---

## 5. The Cleanup

Feature has been rolled out to 100% for 6 months.

**Question:** When do you remove the flag? What happens if you don't?
