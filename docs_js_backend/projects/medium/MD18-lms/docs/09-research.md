# Research Notes

## LMS Industry Patterns

### Progress Tracking Models

**Simple Completion**
- Binary: completed/not completed per lesson
- Easy to implement
- Limited granularity

**Time-based Tracking**
- Track time spent per lesson
- Video watch percentage
- More accurate but complex

**Adaptive Learning**
- AI-driven personalized paths
- Difficulty adjustment
- Most sophisticated approach

### Enrollment Management

**First-Come-First-Served**
- Simple queue system
- Race condition risks

**Waitlist System**
- Queue for full courses
- Notification when spot opens

**Lottery System**
- Random selection for high-demand courses
- Fair but complex

### Quiz Systems

**Immediate Feedback**
- Show correct answer after each question
- Better learning outcomes

**Delayed Feedback**
- Show results at end
- Traditional testing approach

**Adaptive Testing**
- Question difficulty based on performance
- CAT (Computer Adaptive Testing)
