# Phase 2 & 3 Roadmap

## Phase 2: Enhanced Matching

- Stop-loss and stop-limit orders
- Iceberg orders (hidden quantity)
- Post-only and immediate-or-cancel flags
- Market maker rebates

## Phase 3: Production Hardening

- FIX protocol gateway
- WebSocket market data feed
- Historical trade analytics
- Regulatory reporting (MiFID II, Reg NMS)
- Disaster recovery with hot standby

## Advanced Features

- Cross-symbol arbitrage detection
- Machine learning for anomaly detection
- Colocation optimization
- FPGA acceleration for matching
