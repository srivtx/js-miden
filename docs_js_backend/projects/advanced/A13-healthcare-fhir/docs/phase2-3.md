# Phase 2 & 3 Roadmap

## Phase 2: Advanced FHIR

- Bundle transactions (batch/transaction)
- Search parameters (_id, _lastUpdated, name, etc.)
- History API (resource versioning)
- OperationOutcome error handling
- Subscription API for changes

## Phase 3: Production Healthcare

- SMART on FHIR launch
- Bulk FHIR export
- Terminology server integration (SNOMED, LOINC)
- Clinical Decision Support hooks
- Integration with HIE (Health Information Exchange)

## Compliance Enhancements

- Automated HIPAA risk assessment
- Data retention policies
- Right to deletion (GDPR + state laws)
- Break-the-glass emergency access
- Patient portal with full access logs
